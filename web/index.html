使用前请准备（联系作者可代抓）

  1. 打开 模拟器（MuMu / 雷电 等）并等待完全启动
  2. 在模拟器里打开 旅行青蛙 并登录到能正常游玩的界面
  3. 保持模拟器和游戏运行，回到这里点「开始抓取」
  4. 抓取过程中游戏会被自动重启并点击「进入游戏」，请不要手动操作模拟器
  5. 华为渠道服额外需要 HMS Core 与华为账号登录，见下方「华为渠道服」卡片
抓取结束后，请手动重开一次游戏，让模拟器恢复正常联网。
